Root cause fixed this slice
----------------------------
Mode A FE BIND historically preferred WVM_RUNTIME_LOCAL_PORT (V30 sidecar)
as SET_GATEWAY. Kernel :9000 REMOTE_RUN → V30 → Hybrid replaced the UDP
client with LOCAL_PORT; Hybrid Ack returned to V30 and never woke the
kernel waiter (hairpin loss; s23g10/g11 FAIL). s23g12 dual-send to :9000
was 「旧版本套上新版本」and was refused/removed.

Charter cutover (wire-ipc §7 / kernel-accelerator §5.2):
  Mode A FE SET_GATEWAY → WVM_EXECUTOR_SERVICE_PORT (Hybrid), same endpoint
  Mode B uses for local handoff. Kernel :9000 <-> Hybrid direct.
  gw9000 dual-send REMOVED from all Slave Ack / FastAck / ErrorAck / cache
  replay sites in slave_hybrid.c.
