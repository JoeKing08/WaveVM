================================================================
结论 / Verdict
================================================================
正式入口现在是 typed 控制路径，不再是独立的 master/slave CLI。

Official production entry is now:
  scripts/wavevm
    -> ctl_tool/wvm_ctl serve
    -> wavevm_node_runtime agent
    -> CREATE_VM on the control socket

Independent wavevm_node_master / wavevm_node_slave are no longer a
supported or advertised production entry. Sources remain in-tree only
for historical non-production harnesses, and those binaries now refuse
to start unless WAVEVM_ALLOW_LEGACY_CLI=1.

Phase 1 不能如实写成已关闭。
Cannot honestly call Phase 1 closed:
  - typed official entry exists and was proven live on 2404
  - independent master/slave production entry is disabled/unadvertised,
    but the binaries and scripts/ci_dual_node.sh still exist as an
    opt-in historical harness (F05/F10/A4 still launch them with the
    allow flag)
  - Phase 1 acceptance also requires more than a same-host smoke

未宣称 / Not claimed:
  MINIMUM_COMPLETE, F05 CLOSED, F10 CLOSED, Phase 9 closed.
A4 official cell remains FAIL / deferred (Joe override this turn;
  recommended QEMU HALT-WAKE wiring fix was not started; prior A4
  evidence was left in place).
F01 / TCG guest OS login stays skipped.
No commit, no push.
Typed runtime gate was not silently flipped. The admitted
wavevm_node_runtime child still activates its per-manifest gate as
before; the legacy CLI ENOTCONN fallback was not "fixed" by enabling
that gate on the independent master/slave path.
