--- N01 [P1] OPEN — 并发 CREATE 不得共享可重置 admission workspace ---
问题：F09 已在 RPC 期间让出 owner 锁，但 ctl_tool/main.c 仍把单份
  admission_workspace（prepared_vm/route/activation/route_tx/snapshot、
  plan provider、capture、transport）绑到 authority；另一 CREATE 可在
  首请求等网时 reset 同一组对象，串 manifest/route/reservation。
  VM fence 加入又晚于 orchestrator prepare/activate RPC。
证据：minimum-new-profile-audit-codex-agent-2026-11-05.txt §N01；
  ctl_tool/main.c admission_workspace_reset / authority_config 单份绑定；
  F09 RESULT 只证让锁，不证隔离（…/F09-owner-lock-concurrency/）。
处置：每次 CREATE/admission 事务隔离可变 workspace（或等价 fail-closed）；
  首次网络让锁前建立同 VM fence；短临界区改共享 inventory/journal。
  禁止用「恢复全局大锁」冒充修复。定向测：两真实 CREATE 交叠，状态不串。
状态：PASS（directed, 2026-11-09）— 共享 workspace 独占租约；忙则 BACKPRESSURE；
  prepare 后/让锁前 fence；reset 拒外线程。证据：
  audit-evidence/fix-blockers-20261109/N01-admission-workspace/
  说明：等价 fail-closed 串行化重叠 CREATE，尚未做多槽独立 workspace。

--- N04 [P1] OPEN — 同 VM 唯一 KVM FE 所有权 ---
问题：runtime 可为 KVM 自动起一个 -S -nodefaults QEMU 并 READY；guest 脚本
  再用同 manifest 另起带盘/网 QEMU。runtime gate 按连接分 slot，不限制
  QEMU_FRONTEND 来自同一进程 → 同 VM 可出现两个 FE 进程。
证据：Codex §N04；master_core/main_wrapper.c spawn_manifest_bound_qemu_frontend；
  tests/e2e/test_guest_smoke.sh 先 CREATE RUNNING 再另起 guest FE；
  common_include/wavevm_runtime_gate.c wvm_runtime_gate_register。
处置：唯一 FE 生产启动/配置/所有权；拒同 manifest 第二不同 FE PID；
  FE STOP 有界。保留同进程多连接。
状态：PASS（directed gate, 2026-11-09）— 不同 process_instance 第二 FE 拒绝；
  同进程多连接仍可。证据：
  audit-evidence/fix-blockers-20261109/N04-unique-kvm-fe/
  残留：guest_smoke/自动 paused FE 双进程路径现会 fail-closed；F10 须收成
  唯一 FE 启动/就绪流程（非再开 gate 漏洞）。

--- N03 [P1] OPEN — QUIESCE / 成员失效须证明执行已收住 ---
问题：QUIESCE_RUNTIME 对首个失败 participant 即返，其余健康方未 quiesce；
  agent 向 child 发 SIGUSR1 即报成功，但 child_execution_fail_closed 未注册
  为 SIGUSR1 handler（仅 SIGTERM/SIGINT）→ 默认杀进程 ≠ 有序 quiesce ACK。
证据：Codex §N03；ctl_tool/main.c execution_fail_closed_hook；
  wavevm_admission_runtime_agent.c quiesce_one_runtime；
  node_runtime/main.c child_execution_fail_closed + 信号安装；
  F08 RESULT 定向 PASS 不能盖本项。
处置：有界处理其余可达参与者；执行 gate/工作线程参与 quiesce 并 ACK；
  若用 fail-stop 须明确失败结果与补偿，不得把 kill 返回当屏障成功。
状态：PASS（directed, 2026-11-09）— SIGUSR1 已注册；多 participant 继续；
  slot gate QUIESCING 作 ACK。证据：
  audit-evidence/fix-blockers-20261109/N03-quiesce-sigusr1/
